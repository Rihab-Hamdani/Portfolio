# Images

- `profile.jpg` — put your real profile photo here (square, at least 800×800, ideally WebP/JPEG under 200 KB).
  Until it exists, the hero shows a styled "RH" monogram. No generated face is ever used.
- Project screenshots — put them in `public/projects/<project-slug>/` and add them to the project
  from the admin dashboard (Projects → Edit → Screenshots) using paths such as
  `/projects/medical-cabinet-stock-management/dashboard.webp`.
